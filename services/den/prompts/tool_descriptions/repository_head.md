Read the remote commit SHA of one managed GitHub repository's configured branch. Supply only its work_surface_id UUID. Den checks the current source, hat's exact repository permission, host/resource ceilings and your separately owned Connection before and after I/O; neither a UUID nor a hat grants credential access. This does not fetch repository contents, synchronize a checkout or publish changes. Credential material and backend references are never returned. External credential custody is not configured in this slice: calls report credential_unavailable until an operator integrates a backend; legacy encrypted tokens, SSH keys and GitHub App installations cannot be used as a fallback.
