Help: how context is assembled

Turns use bounded components: the Bear base, mode and hat purpose, matching standing notes, projected memory, recent conversation and tool descriptors. Recall can retrieve additional memory on demand.

Component token estimates in a recorded budget describe that turn. Stored prompt and note previews on this page may come from different times; they do not reconstruct the exact request or predict a future turn.

Durable knowledge belongs in Memory; the transcript window is bounded. Inspect available tool descriptors under Tools.
