Help: how PKCE testing works

This checks whether a verifier matches its challenge. It does not test a complete authorization flow or change the client.

A client sends a challenge with its authorization request, then the original verifier with its token request. The server recomputes the challenge to prevent an intercepted authorization code from being used without the verifier.
