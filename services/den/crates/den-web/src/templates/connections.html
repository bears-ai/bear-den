How reusable accounts work

HTTPS tokens, SSH keys and GitHub App installations are supported. An account owner who also manages a repository can attach their account to it. Repository managers can detach links; only the account owner can revoke the account. To replace secret material, create a new account and replace each intended repository link, then revoke the old account if no longer needed.
