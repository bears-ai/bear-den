# Stance vocabulary

Current working-tree WIP uses **Bears**, **hats**, **canonical sources**, **work surfaces**, **channels**, **armatures**, and **governance**. It is not latest-image shipment evidence; see [the maintained topic](../topics/bear-memory-hats.md).

## Core terms

| Term | Meaning |
| --- | --- |
| Bear | Durable assistant identity. |
| Hat | Bear-owned responsibility/identity and policy boundary, selected from the canonical conversation or eligible Job. Mandatory for ordinary execution, even on zero-hat Bears. It does not itself grant a tool, credential, workspace, or Job. |
| Canonical source | Owned conversation or exact eligible live Work run; owns private notes and execution admission. |
| Channel | Human conversation surface; not automatically a trusted local work harness. |
| Armature | Trusted client harness with actual local tools, workspace roots, and permission obligations. |
| Work surface | Durable resource/environment ceiling, not an independent grant. |
| Governance | Current supervision state; can narrow capabilities, never invent a source or connected armature. |
| Runtime-context label | Derived metadata for channel, armature, Job, curation, or observation. The Rust type is `RuntimeContextLabel`; the named aliases are removed. Historical `chat/pair/work/curate/watch` encoding remains schema/audit data, not configurable stance authority. |

## Preferred framing

Explain one Bear wearing a selected hat in an owned conversation or eligible Job, using resources and concrete permission decisions. Admin stance detail/configuration/provisioning is retired; old rows/contracts/settings are historical inspection data. No autogenerated default hat, imported permission, or automatic promotion is implied.

Use “stance”, “profile”, and “agent” only when discussing historical rationale, legacy schema fields, or specific compatibility/projection names. Derived metadata cannot reconstruct verified origin, select live model/loop settings, or authorize memory/tools. Browser task sessions remain a distinct origin despite their historical `pair` encoding.

The source-admission cutover is not a complete hat-grant resolver: broader Den effects and bounded persistent client choices remain in [Gate 0A](../roadmap/HATS_AND_SESSION_MEMORY_BOUNDARIES_PLAN.md#gate-0a--hat-owned-tool-and-network-permissions-partial-cutover-exit-pending).
